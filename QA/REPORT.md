# Проверка 0.35.0

Проверялся index.html непосредственно из этой папки сборки.

- 60 механических регрессионных тестов: пройдено.
- 20 новых проверок исправлений, восстановления и баланса: пройдено.
- 8 проверок отказов сохранения и облачного клиента на имитированном сервере: пройдено.
- Синтаксис JavaScript и наличие статических ассетов: пройдено.
- Edge: 320×568, 360×640, 390×844, 430×932, 768×1024, 1366×768. Основные боевые действия доступны, горизонтального переполнения нет.
- Пройдено: выбор героя, пять разделов меню, подробности по удержанию без розыгрыша, покупки, лимит двух покупок, вызовы всех 30 активных предметов.
- Проверено восстановление до действия, сразу после действия и в лавке; переходы Boss Rush, подземелья и драфта; однократная выдача награды.
- В браузерных сценариях не зарегистрировано ошибок JavaScript.
- Стресс-симуляции сохранены отдельно: это сравнение ИИ в симметричных условиях без лавки и активных предметов, а не доказательство соревновательного баланса.

Границы проверки: реальный Telegram, Android/iOS, длительные человеческие сессии и работающий удалённый API не проверены. В пакете отсутствует PvP-сервер. Перед публичным онлайн-релизом нужны серверная проверка экономики, два клиента, переподключение и нагрузочный тест.

Изображения сохранены из предыдущей сборки без изменения байтов. Права на исходные портреты и другие исходные материалы этим техническим прогоном не проверялись.
