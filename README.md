# Game of Dolbaebers · 0.36.5

Карточная PvE-игра и первая версия дружеских дуэлей по коду комнаты.

## Изменения 0.36.5

- В плашку первого вайпа добавлена фотография Данила. Вайп выполняется только один раз по постоянному ключу `god_global_wipe_2026_v1`; будущие обновления не запускают его повторно.

## Изменения 0.36.4

- Каждый третий успешный удар Максоса теперь полностью повторяет исходную атаку; карточные/предметные двойные удары используют тот же механизм полного повторного попадания.
- Качество артефактов влияет на фактические характеристики. Объединение трёх свободных предметов повышает редкость выбранного предмета, а профиль сохраняет новую редкость после перезапуска.
- Максимальная редкость отображается как «БЛЯДОНСКОЕ» с радужным оформлением; внутренний ключ сохранён для совместимости.
- Дроп подземелья стал реже и сбалансирован по комнатам. Сам вход в подземелье временно заблокирован плашкой о балансировке.
- Добавлен выход из боя с подтверждением. Незавершённый бой завершается без наград; уход из Boss Rush и подземелья сбрасывает соответствующий забег.
- Стартовый экран использует баннер из `assets/onboarding-banner.jpeg`. Исправлены мобильные отступы карточки дуэли, сцены боя и экрана выбора героя.
- Обновлено обучение: добавлены правила объединения артефактов, текущие названия редкостей и состояние режимов.

## Изменения 0.36.2

- Повышение качества артефактов теперь реально усиливает их эффекты.
- Boss Rush больше не наносит процентный урон от HP через случайные адаптивные артефакты; после 9-го этапа кривая сложности ускоряется.
- Исправлено центрирование декоративных символов в боевой лавке.

- Лавка PvE открывается отдельной кнопкой «Лавка у костра» в бою. Покупки доступны в свой ход перед действием, до двух за раунд; покупки не расходуют ход. Раунды продолжаются автоматически.
- Сброс тестового прогресса выдаёт 20 000 золота, стартовые сундуки и пустой инвентарь.
- Новый профиль также начинает без выданных предметов. Пассивные артефакты и активные предметы добываются из сундуков; активные открываются без повторов и выбираются в отдельный слот.
- Старый полный тестовый набор активных предметов убирается при миграции. Уже добытые пассивные артефакты и существующее золото сохраняются; коллекция новой версии сохраняется между перезагрузками.

## Запуск дуэлей

Нужен **Node.js 24**. Из папки проекта:

```sh
node server/main.cjs
```

Либо на Windows запусти **ЗАПУСТИТЬ_ОНЛАЙН.cmd**. Открой `http://localhost:3000`, затем **Арена → Играть с другом**. Первый игрок создаёт комнату, второй вводит код или открывает ссылку-приглашение. Оба подтверждают героя и пять карт.

Для локального теста используй два независимых браузера или обычное и приватное окно. Для друзей через интернет понадобится HTTPS-хостинг серверной части. GitHub Pages обслуживает одиночную игру, но не запускает Node.js.

**Пошаговое размещение:** [ONLINE_SETUP_0.36.0.md](ONLINE_SETUP_0.36.0.md). Подготовлены `render.yaml` и Dockerfile. Постоянный диск Render требует платного сервиса; создание аккаунта/сервиса и подтверждение оплаты остаются отдельным действием пользователя. Публичный онлайн-сервер автоматически не создавался.

## Что поддерживается

- Приватная комната на двух игроков, гостевой вход и ссылка-приглашение.
- Шесть героев, 52 карты; каждому пять выбранных и пять общих случайных карт.
- Сервер проверяет руку, ману, очередь, оглушение, урон, лечение и исход боя.
- Ход до 120 секунд, максимум 24 раунда; сдача и реванш.
- Сохранение матча в SQLite, повторное подключение после перезагрузки или рестарта сервера.
- Защита от повторного выполнения команды, конфликтов ревизий и просмотра чужой руки.

В дружеских дуэлях нет предметов и усилений PvE, межраундовой лавки, активных предметов, рейтинга и наград. Локальный PvE сохраняется отдельно и остаётся доступен.

## Проверки

```sh
node --test server/tests/duel.test.cjs server/tests/api.test.cjs
```

Сервер использует текущую боевую логику игры через адаптер без активного DOM и таймеров; клиент не передаёт готовый урон или характеристики. В репозиторий нельзя добавлять каталог данных SQLite и настоящие `.env`-файлы. Это закрытый прототип для друзей: перед массовым запуском нужны нагрузочное тестирование и дальнейший баланс.
